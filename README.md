A program that writes "The Hand That Stops", a short original poem about agency: the power to stop and to stay. A hand hangs still over a singing kettle, a door stands half-open with the key half-turned — and stopping, the poem says, is itself a kind of staying.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
